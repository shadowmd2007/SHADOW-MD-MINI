Link your WhatsApp with a pairing code

Digits only. No +, no leading 0. Example: 923001234567

  1. Enter your number above and tap Get pairing code.
  2. On your phone open WhatsApp → Settings → Linked devices.
  3. Tap Link a device, then Link with phone number instead.
  4. Type the code shown here. This page confirms only when WhatsApp is really connected.
